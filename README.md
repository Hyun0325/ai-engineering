# AI Engineering

Mechanical Engineering based AI Learning & Research Portfolio


## Introduction

This repository is a personal AI engineering portfolio that combines mechanical engineering knowledge with artificial intelligence technology.

The purpose of this project is to develop programming skills, understand machine learning and deep learning concepts, and explore how AI techniques can be applied to engineering problems.


## Background

I am a mechanical engineering student interested in applying artificial intelligence to mechanical systems and mobility engineering.

Through this project, I aim to build practical skills in Python programming, data analysis, deep learning, and engineering applications.


## Development Environment

- OS: macOS (Apple Silicon)
- Editor: Visual Studio Code
- Programming Language: Python 3.11
- Environment Management: Miniforge (Conda)
- Deep Learning Framework: PyTorch
- GPU Acceleration: Apple Metal Performance Shaders (MPS)
